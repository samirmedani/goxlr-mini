# GoXLR Mini — archive

Le développement continue dans **[Rustudio](https://github.com/samirmedani/rustudio)**, l’application modulaire qui inclut le module GoXLR Mini.

- **Nouvelle installation :** [télécharger Rustudio](https://github.com/samirmedani/rustudio/releases/latest).
- **GoXLR Mini 4.x déjà installé :** clique sur **Mettre à jour** dans l’ancien logiciel pour passer à Rustudio. Le [pont de migration v5.0.0](https://github.com/samirmedani/goxlr-mini/releases/tag/v5.0.0) reste disponible pour cette mise à jour.
- **Aide et contributions :** utilise [le dépôt Rustudio](https://github.com/samirmedani/rustudio).

Ce dépôt historique est conservé en lecture seule.
